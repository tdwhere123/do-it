# Worklog template

Copy to `.do-it/worklog/YYYY-MM-DD.md` or `.do-it/worklog/<goal-slug>.md`.

Progress, experiments, and session notes live here. Do not copy them into
`.do-it/plans/` — those files are execution contracts (Goal / Decisions /
Boundary / Acceptance), not construction logs.

```markdown
# <goal one-liner>

**Date:** YYYY-MM-DD
**Status:** active | blocked | done

## Intent

What we are trying to accomplish this session (1–3 sentences).

## Current truth

- Branch / worktree:
- Files touched:
- Commands run:

## Decisions

- Settled choices (cite the contract if one exists):

## Evidence

- Command or inspection — result

## Next

- Next concrete step
- Verification command

## Residual risk

What is not proven yet.
```

Keep handbook stable; put churn here.
