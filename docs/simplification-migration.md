# Simplification migration

The default runtime now delivers compact context and useful source-edit checks.
Choose professional skills directly. `do-it-router` is removed without an alias
or replacement entrypoint. Managed upgrades remove unchanged owned copies; modified
user copies require explicit resolution. Workflow tiers, lexical router/grill
prompts, completion language gates, and automatic active-task takeover are retired.

The specialist set now has eight roles. `decision-challenger` replaces
`product-strategist` and `plan-challenger`; `reviewer` also owns requirements and
scope review previously assigned to `spec-compliance-reviewer`; `test-engineer`
replaces `tdd-red-writer` with a test-only write scope that still honors an
explicit RED-only handoff. These are capability choices, not a required sequence
or a measured performance improvement. Use host-native general workers for
implementation when they already cover the assigned outcome.

Rebuilt bundles no longer expose the retired names. Managed Codex upgrades
remove only unchanged owned role files. Modified, unowned, or configured file
consumers require explicit resolution; force does not authorize deleting them.
User/project Pi roles are not managed package copies and are not removed.
Read-only roles stay read-only; writer commits or other repository side effects
require explicit authorization within the assigned write scope. Tool availability
alone does not enforce test-only or documentation-only write boundaries.

The custom adaptive system is removed in full: profile selection and injection,
candidates, shadow/activation/promotion, automatic recording, and policy tooling.
Use the native host's persistent instructions or memory for preferences. If you
want to transfer a preference, inspect your old profile yourself and copy only
what you still want into the native mechanism. The plugin does not read, modify,
migrate, or delete existing profiles or memory. Existing task docs and runtime
pointers also remain untouched and inert.

`/do-it-retrospective` now requests on-demand reasoning about an observed episode;
it does not enable learning events. `/do-it-skip` is a compatibility notice.
`DO_IT_ROUTER_MODE` no longer selects a runtime. Evidence collection defaults to
off; `DO_IT_EVIDENCE_MODE=observe` enables explicitly requested diagnostics in
Pi. Other hosts can explicitly register or invoke the observer. Event
records are observations, not proof of task acceptance.

Host permissions remain authoritative for enforced access and side effects. The
broad URL-based network admission hook was removed: printing a URL is not a
network request, and command-text heuristics cannot establish user authorization.
The opt-in Claude strict external-action profile remains available for its
precise configured operations.
