# 简化迁移

默认运行时只提供精简上下文和有用的源代码编辑检查。直接按描述选择专业技能；
`do-it-router` 仅保留为显式兼容别名。任务分级、词法 router/grill 提醒、完成措辞
门禁和 active-task 自动接管均已退出。

自定义 adaptive 个性化系统完整移除，包括配置选择与注入、候选、影子运行、激活、
晋升、自动记录和策略工具。偏好交给宿主原生持久指令或记忆。如果需要迁移，请自行
检查旧配置，仅将仍然需要的偏好复制到原生机制。插件不会读取、修改、迁移或删除
现有用户配置、记忆、任务文档或运行时指针。

`/do-it-retrospective` 现在只按需复盘，不启用自动学习事件。`/do-it-skip` 仅提供
兼容说明。`DO_IT_ROUTER_MODE` 不再选择运行路径。证据收集默认关闭；显式设置
`DO_IT_EVIDENCE_MODE=observe` 可在 Pi/OpenCode 启用诊断，其他宿主可显式注册或
调用 observer。诊断事件只是观察记录，不能证明任务验收。

宿主权限负责执行访问和副作用限制。宽泛的 URL 网络探测钩子已移除：打印 URL
不代表发送请求，命令文本启发式也无法确定用户授权。Claude 的可选严格外部操作
配置继续保留，对其明确配置的操作生效。
