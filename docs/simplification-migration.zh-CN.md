# 简化迁移

默认运行时只提供精简上下文和有用的源代码编辑检查。直接按描述选择专业技能。
`do-it-router` 已删除，不保留别名或替代入口。托管升级会删除归属明确且未修改的旧副本；
用户修改过的副本需要明确处理。任务分级、词法 router/grill 提醒、完成措辞门禁和
active-task 自动接管均已退出。

专业代理现在收敛为八个角色：`decision-challenger` 合并 `product-strategist` 与
`plan-challenger`；`reviewer` 同时负责原 `spec-compliance-reviewer` 的需求与范围评审；
`test-engineer` 替代 `tdd-red-writer`，只写测试相关文件，并继续遵守明确的 RED-only
交接。这是能力整理，不是必经流程，也不代表已测得性能提升。宿主的通用 worker
已经能承担指定实现结果时，直接复用即可。

重新构建的包不再暴露退役名称。Codex 托管升级只删除未修改且归属明确的旧角色文件；
修改过、未托管或仍被配置引用的文件需要明确处理，force 也不授权删除它们。Pi 的
用户 / 项目角色不是托管包副本，不会被删除。只读角色仍只读；写入角色提交或执行
其它仓库副作用，必须在已授予的写入范围内获得明确授权。工具可用不代表宿主能
强制隔离“仅写测试”或“仅写文档”的范围。

自定义 adaptive 个性化系统完整移除，包括配置选择与注入、候选、影子运行、激活、
晋升、自动记录和策略工具。偏好交给宿主原生持久指令或记忆。如果需要迁移，请自行
检查旧配置，仅将仍然需要的偏好复制到原生机制。插件不会读取、修改、迁移或删除
现有用户配置、记忆、任务文档或运行时指针。

`/do-it-retrospective` 现在只按需复盘，不启用自动学习事件。`/do-it-skip` 仅提供
兼容说明。`DO_IT_ROUTER_MODE` 不再选择运行路径。证据收集默认关闭；显式设置
`DO_IT_EVIDENCE_MODE=observe` 可在 Pi 启用诊断，其他宿主可显式注册或
调用 observer。诊断事件只是观察记录，不能证明任务验收。

宿主权限负责执行访问和副作用限制。宽泛的 URL 网络探测钩子已移除：打印 URL
不代表发送请求，命令文本启发式也无法确定用户授权。Claude 的可选严格外部操作
配置继续保留，对其明确配置的操作生效。
