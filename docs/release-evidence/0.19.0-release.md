## Local Pi pair

The existing Linux Pi configuration now selects these versioned, protected local
sources instead of stock Tintinweb plus a live development checkout:

- `~/.pi/agent/local-packages/do-it-pi-0.19.0`: unpacked verified npm artifact.
- `~/.pi/agent/local-runtimes/tintinweb-0.23.0-do-it-7a48987`: the reviewed,

atomic file replacement. All unrelated settings and **18 custom role/config
files** remained unchanged. The original runtime installation and backups remain
available; no current Pi process was hot-swapped.

10 runnable skills, 8 canonical prompt entries, the `Agent` tool,

must be restarted to load this pair.
