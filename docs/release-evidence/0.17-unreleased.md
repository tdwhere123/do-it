## Residual risk and rollback

Risks if someone switched the default to thin anyway:

- No live or canned kernel trajectory to show non-inferiority vs legacy.
- Prompt shape would change (compact kernel instead of router+grill) on every host at once.
- Evidence observe is fail-open: missing facts are `partial` / `unavailable`, never a hard veto.
- Adaptive overlay would start riding `shadow`/`thin` even with an empty profile (0 extra tokens) and would inject if a profile file appeared.
- Recurring injection cost is unmeasured.
- Six-host live install/upgrade/doctor is unproven on this commit.

**Rollback:** `DO_IT_ROUTER_MODE=legacy` (also the default when the variable is
unset or invalid). Do not delete `hooks/router.sh` or `hooks/grill-prompt.sh`.
Do not tag, push, or publish from this card.
