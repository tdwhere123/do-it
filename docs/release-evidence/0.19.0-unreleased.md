## Primary-runtime migration gate

The Tintinweb creator-identity patch remains in isolated source worktrees at
this checkpoint, not integrated into the live-linked main plugin. The user's
installed unpatched Tintinweb 0.23.0 does not expose that capability. Removing
the existing detector alone would change child routing on reload. Integration
therefore requires completed lifecycle evidence and an authorized paired
migration, not merely a passing unit test or an `unsupported` label.

The existing main detector retains its known in-memory/nested-child limits.
This checkpoint does not claim complete Tintinweb support, saved-child role
transition support, or that any installed runtime/settings/global roles changed.
