# 0.19.0 prompt-only behavior pairs

Six authorized Grok 4.6 xhigh runs completed: one published/candidate pair for
each of three **controlled replays of observed defects**. They are read-only
source investigations, not fresh production tasks or tests of a complete plugin
release. There is one sample per condition and class. These observations do
**not** establish a statistical gain, release effectiveness, or behavior on
other models.

**Important contamination:** the candidate identity run read and cited its
faithful `skills/do-it/references/host-pi.md`, which explicitly describes the
same root-under-`/agents/` problem and its identity boundary. That answer was
present in subsequent model requests. The identity pair is therefore **not a
blind test** of discovering that fix; no gain is claimed from the difference.
The experiment rubric and historical answer artifacts were not mounted into
workers, but isolating those did not prevent an answer-bearing *candidate
instruction reference* from being read. No prompts were tuned after results.

skips. It includes the bounded gateway and six-job fake-provider tests, the


To reconstruct the **inputs only**, using a new ignored output directory and a
fresh npm download (no generation request):

```bash
npm pack @tdwhere/do-it@0.18.1 --ignore-scripts --pack-destination /tmp --json
node evals/behavior/pairs/prepare.mjs evals/behavior/runs/NEW-DISTINCT-NAME /tmp/tdwhere-do-it-0.18.1.tgz
```
