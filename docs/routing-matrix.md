# Skill Discovery

Select professional skills directly from their descriptions or the generated
index. There is no required router entry, task tier, or fixed workflow chain.
The do-it-router skill preserves old explicit references as a minimal alias.

Use independent specialists when separate contexts and evidence gathering can
improve a concrete decision or bounded work slice. Preserve role boundaries;
the parent integrates and verifies. See the [skills overview](../README.md)
and [host matrix](./harness-adapter-matrix.md).
