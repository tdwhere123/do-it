# Task Notes

A durable note helps when decisions must survive a handoff or context loss.
Reuse existing plans or project docs. Record only useful information: goal,
settled decisions, authorization boundary, acceptance, and unresolved questions.
No heading grammar, identifiers, scaffold, or progress format is required.

An explicit user reference or handoff identifies the active task. A shared
runtime pointer does not select or revive a task automatically. Preserve old
user documents and pointers; the plugin neither migrates nor deletes them.
